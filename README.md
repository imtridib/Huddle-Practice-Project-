# Huddle Landing Page

A responsive static landing-page implementation inspired by the Frontend Mentor Huddle challenge. The page uses HTML and CSS, with local image assets and web fonts.

## Tech stack

- HTML5
- CSS3
- Google Fonts
- Local SVG/image assets

## Run locally

Open `index.html` in a browser, or use VS Code Live Server. Keep the `images/`, `design/`, and stylesheet files in their current relative locations.

## Status

This is a static front-end practice project. The original challenge assets and design references may be included in the repository.
